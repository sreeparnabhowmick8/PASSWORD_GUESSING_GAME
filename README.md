# PASSWORD_GUESSING_GAME
# 🔐 Number Password Guessing Game

A beautiful Number Password Guessing Game built using **Python Tkinter GUI**.

This project allows users to guess secret numeric passwords with different difficulty levels, hints, scoring system, and an interactive modern UI.

---

## ✨ Features

✅ Beautiful GUI using Tkinter  
✅ Easy, Medium, Hard difficulty levels  
✅ Random numeric password generation  
✅ Hint system after every wrong guess  
✅ Score calculation system  
✅ Remaining attempts tracker  
✅ Extra hints when attempts are low  
✅ Game Over and Win popups  
✅ Modern dark-themed interface  
✅ Enter key support  

---

## 🖥️ Technologies Used

- Python
- Tkinter
- Random Module

## 🎮 How to Play

1. Enter your name
2. Select difficulty level
3. Click **START GAME**
4. Guess the secret number password
5. Use hints to find the correct password
6. Win the game before attempts end

---

## 🔢 Difficulty Levels

| Level | Password Length | Attempts |
|------|------|------|
| Easy | 4 Digits | 10 |
| Medium | 5 Digits | 7 |
| Hard | 6 Digits | 5 |
